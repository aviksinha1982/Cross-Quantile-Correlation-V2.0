The codes are for computing Cross-Quantile Correlation with 1000 bootstraps.

The codes are made for 19 quantiles. The codes use Stata-MATLAB integration. First, the Cross-Quantile Correlations and respective p-values are computed in Stata, and then the Heatmaps are generated in MATLAB. MATLAB will be automatically called by Stata, and therefore, the user must have MATLAB installed on his/her computer.

The dataset (.dta) should contain only two variables
